# ADdetection

Detecting Alzheimer's disease (AD) from spontaneous speech. The model fuses two views of each recording:

- **Log-mel spectrograms** → a CRNN branch (CNN blocks + BiLSTM)
- **eGeMAPS acoustic features** (88-dim, via openSMILE) → an MLP branch

The two embeddings are concatenated and passed to a small classifier (Control vs. AD). The model is evaluated with 5-fold subject-level cross-validation.

## Results

5-fold CV, hybrid model, threshold 0.5:

| Metric    | Mean  | Std   |
|-----------|-------|-------|
| Accuracy  | 0.795 | 0.176 |
| Precision | 0.744 | 0.181 |
| Recall    | 0.927 | 0.057 |
| F1        | 0.819 | 0.136 |
| F2        | 0.878 | 0.093 |

Pooled ROC-AUC is **0.91** and PR-AP is **0.90**. Ablations show the fusion matters. Log-mel alone reaches 0.49 accuracy (AUC 0.51), and eGeMAPS alone reaches 0.49 accuracy (AUC 0.49). `test_cv5.py` regenerates the full figures and per-fold CSVs.

Early stopping and model selection use **F2**, which weights recall over precision because missing an AD case costs more than a false alarm.

## Data

Audio comes from the ADReSS / ADReSSo challenge sets on [DementiaBank](https://dementia.talkbank.org/). Access requires DementiaBank membership, so **no audio, features, or labels are included in this repo**.

## Project layout

The scripts expect this repo to sit inside a project folder, with data next to it:

```
ADmci_proj/
├── clip_labels.csv          # generated by no_chunks/clip_labels.py
├── labels.csv               # subject-level labels: filename,label
├── data/
│   ├── raw/                 # original recordings
│   └── processed/
│       ├── cleaned/         # <id>.interviewee_only.wav
│       ├── logmel/          # <id>.npy
│       └── eGeMAPS/         # <id>.npy
└── scripts/                 # ← this repo
```

`PROJECT_ROOT` is resolved as the parent of `scripts/`. A few scripts (`clean_files.py`, `no_chunks/eGeMAPS-clips.py`) still hardcode absolute Windows paths, so edit those before running them on another machine.

## Pipeline

Run from inside `scripts/`:

```bash
# 1. Remove interviewer speech (faster-whisper + text rules, requires ffmpeg)
#    Edit RAW_AUDIO_DIR / OUT_DIR at the top of the file first.
python clean_files.py

# 2. Full-clip features
python no_chunks/clips_spectrograms.py      # → data/processed/logmel
python no_chunks/eGeMAPS-clips.py           # → data/processed/eGeMAPS

# 3. Build the clip-level label CSV
python no_chunks/clip_labels.py             # → ../clip_labels.csv

# 4. Train 5-fold CV
python train_cv5.py                         # → models/cv5_fullclip_fold{1..5}_best.pth

# 5. Evaluate + generate poster figures
python test_cv5.py                          # → poster_outputs/
```

## Files

**Core**

| File | Purpose |
|------|---------|
| `model.py` | `HybridCRNNModel` with `hybrid`, `logmel_only`, and `egemaps_only` modes |
| `dataset_no_chunks.py` | Full-clip dataset (`ADClipDataset`) + padding collate |
| `dataset.py` | Dataset used by `train_cv5.py` (`ADChunkDataset`) |
| `train_cv5.py` | 5-fold subject-level CV, focal loss, AMP, early stopping on F2 |
| `test_cv5.py` | Evaluation, ablations, ROC/PR curves, confusion matrices |
| `clean_files.py` | Strips interviewer turns using Whisper transcripts |
| `no_chunks/` | Full-clip feature extraction and label building |

**Alternative / earlier approaches**

| File | Purpose |
|------|---------|
| `diarize_speakers.py` | pyannote speaker diarization (needs `HF_TOKEN`), see `README_IMPROVEMENTS.md` |
| `spectrograms.py`, `eGeMAPS.py`, `build_chunk_labels.py` | 10 s chunked feature extraction (3 s hop) |
| `train.py`, `test.py` | Single-split chunk-level training / testing |

## Setup

Python 3.10+ and ffmpeg on `PATH`. A CUDA GPU is recommended.

```bash
pip install torch torchaudio numpy pandas scipy scikit-learn matplotlib \
            soundfile audioread opensmile faster-whisper tqdm
# only for diarize_speakers.py:
pip install pyannote.audio
```

`diarize_speakers.py` reads a Hugging Face token from the `HF_TOKEN` environment variable. Never hardcode it.
